# Portfolio — Jahanad

My personal portfolio website — plain HTML, CSS, and JS, no build tools.

Preview

**Live:** https://jahanad-pr.github.io/Portfolio-jahanad/

## Run Locally

Just open `index.html` in your browser. No install needed.

Or serve it locally:
```bash
git clone https://github.com/Jahanad-pr/Portfolio-jahanad.git
cd Portfolio-jahanad
npx serve .
```

## Deploy

Already live via **GitHub Pages** with a custom domain (`CNAME` file included).
To update: push changes to `main` — Pages redeploys automatically.
